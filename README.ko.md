# ChoiBuddy

[English](README.md) · **한국어**

PC에서 돌아가는 Claude Code의 작업을 캐릭터와 함께 실시간으로 보여 주고, 권한 요청·질문·계획 승인을 윈도우 위젯이나 휴대폰에서 바로 답하게 해 주는 도구예요. 화면은 한국어, English, 日本語, Français를 지원해요.

![Claude가 코드를 쓰는 순간을, 실시간으로](promo/ko/01-live.png)

**[최신 릴리스 내려받기](https://github.com/choidevhi/choibuddy/releases/latest)**: 윈도우 10/11용 `ChoiBuddy_<버전>_x64-setup.exe`, Android 8.0 이상용 `ChoiBuddy-<버전>.apk`

```
Claude Code ──훅(HTTP)──────▶ 브리지(Node, PC) ──SSE──▶ 윈도우 위젯 + 플로팅 버디 (Tauri)
            ──mod(사용량·프롬프트)─┘      └──Tailscale──▶ 안드로이드 앱 (WebView + 알림)
```

## 무엇을 하나

![허용과 거부는 어디서든](promo/ko/04-approval.png)

- **어디서든 승인.** 권한 요청(허용/거부/항상 허용), Claude의 질문(선택지 답), 계획 승인(승인/수정 요청). 터미널 대화상자와 **동시에** 뜨고, 먼저 누른 쪽이 적용돼요. 590초 안에 아무도 안 누르면 터미널 대화상자만 남아요.
- **지금 하는 일.** 읽는 파일, 고치는 줄(빨강/초록), 실행 중인 명령과 출력, 검색, 할 일 목록.
- **써지는 대로 보이는 코드.** Claude가 쓰고 있는 코드와 답이 한 단어씩 보여요(LIVE).
- **상태마다 다른 표정.** 생각 중, 읽기, 편집, 명령 실행, 승인 대기, 완료, 오류 등. 서브에이전트는 색이 다른 작은 캐릭터로 따로 보여요.
- **사용량.** 5시간·주간 한도, 컨텍스트, 토큰, 캐시 비율, 지금 쓰는 모델과 effort. 홈에서 모델과 effort를 바로 바꿔요.

![PC별로, 여러 대화를 나란히](promo/ko/02-split.png)

- **어디서나 PC별로.** 홈, 대화, 이미지 탭이 모두 같은 3단이에요. 왼쪽에 연결된 PC가 색이 다른 버디로 서 있고(올리면 PC 이름), 그 옆에 고른 PC의 세션이 진행 중, 종료됨(구분선 아래), 보관함 순서로 나와요. 오른쪽이 화면이에요.
- **tmux처럼 화면 나누기.** PC에서는 홈과 대화를 좌우나 위아래로 나누고, 나눈 칸을 또 나눠요(최대 6칸). 경계선을 끌어 크기를 바꾸고, 배치는 기억돼요. 홈 칸은 세션을 고르기 전까지 바쁜 세션을 자동으로 따라가요.
- **대화.** 세션 기록에서 대화 전체를 보고, Claude가 연 이미지와 내가 보낸 사진도 그 자리에 실시간으로 보여요. 프롬프트와 파일을 보내요(홈에서도). 첨부한 사진은 입력창에서 썸네일로 보이고, 보내면 내 말풍선 안에 사진으로 들어가요(경로 목록은 안 보여요). 보낸 프롬프트는 대기 중엔 흐리게, 기록에 들어갈 때까지 같은 말풍선 하나로 남아서 깜빡이지 않아요. 보내지 않은 입력과 첨부는 세션마다 따로 남아서, 다른 세션에 갔다 와도 그대로예요.
- **세션 메뉴.** 세션을 우클릭(휴대폰은 길게 누르기)해서 이름 바꾸기, 세션 종료(Claude Code에 `/exit`), 플러그인 다시 불러오기(`/reload-plugins`), 그 폴더에서 터미널 열기, 보관, 삭제를 해요. 종료된 세션은 접어 두거나, 한 번에 모두 보관하거나 삭제할 수 있어요.
- **예전 mod는 버튼 하나로.** 동반 mod가 바뀌기 전에 시작한 세션은 대화 화면에 알려 주고, 버튼을 누르면 세션이 쉬는 틈에 `/reload-plugins`를 실행해요(×로 그 세션의 안내를 이 기기에서 닫을 수 있어요). mod가 너무 예전 거라 앱에서 보낸 명령을 받지 못하는 세션은, 조금 뒤 대화 화면이 그 세션 터미널에 `/reload-plugins`를 한 번 직접 입력해 달라고 알려 줘요.
- **앱 안 터미널.** 터미널 탭에서 내 PC의 셸(윈도우는 PowerShell, 맥은 로그인 셸)을 앱 안에 바로 열어요. 입력한 글자는 그대로 PC로 가고, 출력은 실시간으로 와요. 나중에 연 화면(다른 기기 포함)도 앞의 내용을 같이 봐요. 휴대폰에는 Esc, Tab, Ctrl+C, 방향키 줄이 붙어요. 세션 목록 위 터미널 버튼은 그 세션 폴더에서 열어요.
- **작업 중에 보낸 프롬프트(스티어링).** **바로 전달**(하던 일을 돌던 도구까지 바로 멈추고 보내요. Claude Code의 "지금 보내기"와 같아요)과 **끝나고 보내기** 중에서 골라요. **Ctrl+Enter**는 언제나 바로 전달이에요.
- **중지.** 작업 중에는 보내기 옆에 **중지**가 떠요. 누르면 터미널의 Esc처럼 하던 일을 바로 멈춰요(돌던 도구까지). 한 일은 남고, 보내 둔 말은 이어서 들어가요. 그 세션의 동반 mod가 0.5.3 이상이어야 해요.
- **슬래시 명령.** `/`를 치면 그 세션의 명령 목록이 나오고, 보내면 명령으로 실행돼 출력이 대화에 보여요.
- **Codex도 (베타).** "새 세션"에서 연 Codex는 ChoiBuddy가 Codex 자체 app-server(`codex app-server`)로 직접 실행해요. 터미널 없이 홈 탭에서 Claude 세션처럼 주고받아요. Codex(CLI나 Codex 앱)만 있으면 되고 훅은 필요 없어요.
  - 모델과 effort를 대화 아래에서 골라요. Codex가 알려 주는 모델과 각 모델이 받는 effort가 나오고, 고른 값은 다음 턴부터 적용돼요.
  - 답이 쓰이는 대로 보이고, 하는 일(명령, 패치, 웹 검색, MCP 도구, 하위 에이전트), todo 목록으로 보이는 계획, 사용량, Codex 계정의 5시간·주간 한도, 만든 그림이 함께 나와요. 첨부한 그림은 Codex에 이미지로 들어가요.
  - Codex가 명령 실행, 파일 수정, 샌드박스 밖 권한(네트워크, 다른 폴더)을 허락해 달라고 하면 어디서든 허용·거부해요. 자동 승인도 그대로 돼요. "항상 허용"은 Codex의 "이 세션 동안 허용"이에요. Codex의 질문은 질문 카드로 떠서 어디서든 답해요.
  - `/`를 치면 Codex 자체 명령 `/compact`, `/review`(커밋 안 한 변경, 또는 뒤에 쓴 내용을 검토)가 나와요.
  - "바로 전달"은 하던 턴을 멈추고 보내고, "끝나고 보내기"는 끝날 때까지 기다려요. 중지는 Esc처럼 지금 턴을 멈춰요. 세션을 종료하면 Codex에서 그 세션을 놓아요.
  - 이 세션들은 브리지가 다시 시작돼도 목록에 남고(최근 30개), 메시지를 보내면 Codex에서 이어서 열어요.
- **다른 곳에서 연 Codex**는 훅으로 보여요. 윈도우 PC에서 ＋ 탭의 "Codex 연결"을 누르고 Codex를 다시 시작하세요. `codex` 명령이 없으면 OpenAI 공식 Codex CLI를 먼저 설치해요(winget). 그다음 훅을 넣고, Codex의 `/hooks` 화면과 같은 방법으로 Codex가 신뢰하도록 해 둬요. 끝까지 되지 않으면 Codex에서 한 번 허용하는 방법을 팝업으로 알려 주고, 버튼 하나로 앱 터미널에서 Codex를 열어 줘요. 이런 세션은 표시가 붙어 보이고, 하는 일, Codex 기록 파일로 읽은 대화, 승인 요청(어디서든 허용·거부)이 나와요. 앱 터미널에서 연 Codex는 어느 기기에서든 프롬프트(Codex 자체 슬래시 명령 포함)를 받아요. ChoiBuddy가 그 터미널에 대신 입력하고, 중지는 거기서 Esc를 눌러요. 그 밖의 곳에서 연 Codex는 밖에서 프롬프트를 받지 않아요. 모든 Codex 세션은 Codex 기록 파일에서 읽은 모델·effort, 컨텍스트, 토큰, 계정 한도를 보여 주고, 만들거나 연 그림은 대화와 이미지 탭에 나와요.
- **자동 언어.** 설정에서 켜 두면, Claude가 앱 언어와 다른 언어로 답했을 때 그 답을 내 언어로 다시 알려 달라고 세션에 한 번 자동으로 보내요(다시 알려 준 답에는 또 보내지 않아요). 연결된 모든 PC에 적용돼요.
- **새 세션.** PC, Claude Code 또는 Codex, 폴더, 첫 프롬프트를 고르세요. Claude Code는 앱 안 터미널에서 열려 바로 입력할 수 있고, Codex는 홈 탭에서 열려요. 원하면 둘 다 PC에 새 창으로 열어요(Claude Code는 이 기기가 그 PC 터미널을 쓸 수 없을 때도). 터미널에서 여는 Codex는 `--no-daemon` 옵션이 있으면 붙여서 열어요. 0.161부터 공유 백그라운드 서버가 winget판과 Codex 앱판에서 시작하지 못해서예요.

![세션 옆에 브라우저, Claude도 같이 봐요](promo/ko/03-browser.png)

- **내장 브라우저(윈도우).** 페이지에서 요소를 골라 프롬프트에 넣고, Claude는 `browser_view` 도구로 같은 화면을 봐요. 브라우저 탭으로 열거나, 작업 중인 세션 오른쪽 칸으로 열어요(칸의 지구본 버튼). 다른 PC의 세션도 돼요. 그 PC의 Claude가 `browser_view`를 부르면, 어느 PC에서든 브라우저를 열어 둔 ChoiBuddy 앱이 답해요.

![Claude가 본 이미지를 PC·세션별로](promo/ko/05-gallery.png)

- **이미지 탭.** Claude가 연 이미지와 스크린샷을 PC별, 세션별로 모아 봐요. GIF도 움직여요. 뷰어에서 확대할 수 있어요. 휴대폰은 두 손가락 벌리기, 끌기, 두 번 탭이고, PC는 휠, 끌기, 더블클릭이에요. 기기에 저장하고, 지우고, PC별로 비워요.
- **단축키.** Ctrl+PageUp과 Ctrl+PageDown으로 탭을 넘겨요.
- **업데이트.** 앱을 켤 때마다, 6시간마다, 30분 넘게 다른 데 있다가 돌아올 때, 그리고 설정의 "업데이트 확인" 버튼을 누를 때 GitHub 새 릴리스를 확인해요. 새 버전이 있으면 상단에 알려 줘요.
  - 윈도우는 눌러서 내려받고 설치한 뒤 다시 켜져요. 브리지, 훅, mod도 승인 대기 중이 아닐 때 알아서 맞추고, Auto Accept는 그대로예요.
  - 휴대폰은 APK를 내려받아 설치해요.

![CLAUDE.md와 AGENTS.md를 바로](promo/ko/06-docs.png)

- **문서 탭.** `CLAUDE.md`, `AGENTS.md`, 서브에이전트 정의를 PC별(왼쪽 버디)·프로젝트별로 보고 고치고 새로 만들어요. 충돌 감지와 백업까지 해요.

![휴대폰에서도 그대로](promo/ko/07-phone.png)

- **안드로이드 앱.** Tailscale로 어디서든 같은 화면을 봐요. 승인 알림에 [허용] [거부] 버튼이 있고, 작업이 끝나면 알려 줘요. 뒤로가기는 열린 것부터 닫고 앱을 내려요.

![홈 화면에도 버디가](promo/ko/09-widget.png)

- **홈 화면 위젯(안드로이드).** 지금 자세의 버디, 세션, 지금 하는 일, 경과 시간, 5시간·주간 사용량. 승인을 기다리는 세션이 맨 위에 와요. 크게 늘리면 다른 세션 두 개까지, 작게 줄이면 버디와 상태만 보여요.

![화면 구석의 작은 버디](promo/ko/08-float.png)

- **플로팅 버디(윈도우).** 승인 요청, 진행, 완료를 말풍선으로 알려요. 끌어서 원하는 곳에 두세요. 우클릭하면 ChoiBuddy 열기, 소리 켜기·끄기, 위치 초기화, 숨기기, 종료 메뉴가 나와요.
- **여러 PC.** 각 PC의 브리지를 함께 봐요. PC의 위험 구간에서 **내 Tailscale 기기 자동 연결**을 켜면, 같은 Tailscale 계정의 다른 기기가 코드 없이 그 PC에 연결돼요(휴대폰은 PC 하나만 QR로 연결해 두면 나머지는 자동).
- **Auto Accept.** 정해 둔 시간 동안 권한 요청을 자동으로 허용해요.

## 시작하기

필요한 것:

- Claude Code
- 휴대폰이나 다른 PC를 쓸 때는 PC와 휴대폰 모두 [Tailscale](https://tailscale.com). 앱이 설치해 줘요: **＋** 탭의 **설치**를 누르면 윈도우는 winget으로 설치하고, 휴대폰은 Play 스토어를 열어요. 로그인만 하면 돼요.

그 밖에는 없어요. 윈도우 앱에 Node.js 24가 들어 있어서 브리지와 Claude Code 훅이 그걸로 돌아가요. Node를 따로 설치하지 않아도 돼요.

순서:

1. **윈도우 앱.** `ChoiBuddy_<버전>_x64-setup.exe`를 설치하고 **Claude Code에 연결**을 눌러요.
   - 브리지와 앱의 Node.js를 `~/.choibuddy/app`에 복사하고 `~/.claude/settings.json`에 훅을 추가해요. 원래 파일은 `settings.json.choibuddy-backup-<시각>`으로 먼저 백업돼요.
   - 동반 mod도 설치해요. 이미 열려 있던 세션은 대화 화면에 "플러그인 다시 불러오기" 버튼이 떠요(터미널에서 `/reload-plugins`를 쳐도 돼요).
   - 설치 파일에 코드 서명이 없어요. SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.
   - **macOS**(아직 릴리스 없음): 이 저장소에서 직접 빌드하고([빌드](#빌드) 참고), `.dmg`를 열어 ChoiBuddy를 응용 프로그램 폴더로 끌어다 놓아요. 서명이 없는 앱이라 처음에는 우클릭 → **열기**로 여세요. 맥용 앱에도 Node.js 24가 들어 있어요. Tailscale **설치**는 다운로드 페이지를 열어 줘요. 내장 브라우저와 앱 안 자동 업데이트는 윈도우에서만 돼요. 새 세션을 처음 열 때 macOS가 Terminal 제어를 허용할지 물어봐요.
2. **휴대폰.**
   - `ChoiBuddy-<버전>.apk`를 설치해요. 브라우저나 파일 앱의 설치 허용을 물으면 허용해 주세요.
   - 윈도우 앱 **＋** 탭에서 **연결 코드 만들기**를 누르고, 나온 QR을 휴대폰 앱으로 찍어요.
   - PC와 휴대폰 모두 Tailscale에 로그인돼 있어야 해요.
3. **다른 PC.** 그 PC에도 설치하고, 거기서 만든 연결 링크를 이 PC 앱의 **다른 PC**에 붙여 넣어요. 휴대폰은 PC마다 QR을 하나씩 찍어요.

윈도우 앱 없이 이 저장소를 받아서 할 때(Node.js 24 이상 필요, 브리지는 설치에 쓴 Node를 복사해 두고 써요):

```
corepack pnpm install
corepack pnpm install-bridge     # 브리지, 훅, mod 설치
corepack pnpm uninstall-bridge   # 훅을 지우고 브리지를 멈춤
```

## 보안

- **훅.** 훅 입력(`/hook`)은 이 PC의 Claude Code만 보낼 수 있어요. 127.0.0.1에서만 받고, 브라우저가 보내는 `Origin` 헤더가 있으면 거부해요.
- **공유기 안 다른 기기에는 안 열려요.** 브리지는 127.0.0.1과 Tailscale 주소(100.64.0.0/10)에만 열려요.
- **연결 코드.**
  - 화면용 API는 모두 코드가 필요해요. PC 앱 자신의 코드는 `~/.choibuddy/config.json`에 있어요.
  - 휴대폰·다른 PC는 기기마다 따로 받은 코드를 쓰고, 파일에는 해시만 남아요. 기기별로 끊거나 전체를 한 번에 바꿀 수 있어요.
  - 휴대폰 앱은 `choibuddy://` 링크로 PC를 더하기 전에 항상 물어봐요. 웹페이지가 몰래 연결하지 못해요.
- **원격 프롬프트.** 코드를 가진 기기만 보낼 수 있어요. bypass 모드에서는 프롬프트가 곧 PC에서의 실행이니, 코드를 PC 접근 권한처럼 다뤄 주세요.
- **파일.**
  - **올린 파일**은 `~/.choibuddy/uploads`에 저장되고, 이름의 경로 문자는 모두 지워요.
  - **이미지**는 Claude가 실제로 연 파일과 도구가 돌려준 스크린샷만 줘요. 임의 경로는 안 돼요. SVG는 스크립트가 돌지 않도록 격리해서 보내요.
  - **대화 지우기**는 진행 중이 아닌 세션의 기록만 `~/.choibuddy/trash`로 옮겨요. 이미지 지우기는 목록만 바꾸고, 브리지가 저장한 스크린샷만 실제로 지워요.
- **문서 탭.** 정해진 이름의 지침 파일만 읽고 써요. 목록에 나온 파일의 id로만, 1MB까지예요. 저장 전 내용은 `~/.choibuddy/doc-backups`에 백업해요. 지침 파일은 Claude의 행동을 바꾸므로, 코드를 가진 기기는 그만큼의 권한을 가져요.
- **Auto Accept.** 메모리에만 있어서 브리지가 다시 켜지면 꺼져요. 일반 권한 요청만 허용하고, 질문과 계획 승인은 사람이 답해야 해요.
- **Tailscale 기기 자동 연결.** 그 PC에서 켜기 전에는 꺼져 있어요. 켜면 Tailscale로 들어온 요청이고, Tailscale이 이 PC와 같은 계정이라고 확인해 줄 때만 기기 코드를 내줘요. 공유받은 기기와 태그 기기는 제외돼요. 연결된 기기는 기기 목록에 보이고 하나씩 끊을 수 있고, 끄면 자동으로 연결된 기기는 모두 끊겨요. Tailscale 계정에 로그인할 수 있는 사람이면 연결할 수 있으니 그 계정을 잘 지켜 주세요.
- **세션 종료**와 **플러그인 다시 불러오기**는 동반 mod로 `/exit`, `/reload-plugins`를 보내요. 터미널에서 직접 입력하는 것과 같아요. **중지**는 mod에 지금 턴을 끝내라고 해요. Esc와 같아요. 코드를 가진 기기는 모두 할 수 있어요.
- **데모용 브리지.** `CHOIBUDDY_HOME`을 따로 주고 띄운 브리지(데모, 스크린샷)는 Tailscale에 나가지 않아요. 거기서 듣지도, 다른 PC를 찾지도 않아서 테스트 화면이 실제 브리지와 연결되지 않아요.
- **Codex.** ChoiBuddy는 이 PC에서 "Codex 연결"을 누를 때만(휴대폰에서는 안 돼요) `~/.codex/hooks.json`에 훅을 써요. 원래 있던 내 훅은 그대로 두고, 바꾸기 전 파일은 `hooks.json.bak`에 남겨요. Codex는 신뢰한 훅만 실행하는데, 버튼을 누르면 Codex 자체 app-server(`codex app-server`의 `hooks/list`, `config/batchWrite`)에 ChoiBuddy 훅만 신뢰해 달라고 해요. `/hooks`에서 하는 것과 같아요. 업데이트로 훅이 바뀌면, 연결돼 있을 때만 브리지가 다시 쓰고 다시 신뢰해요. Codex에 보내는 승인 답은 허용이나 거부뿐이에요.
  - ChoiBuddy가 실행하는 Codex는 PC에서 내 권한으로 `codex app-server`를 띄워 돌고, 내 Codex 설정(승인 정책, 샌드박스)을 그대로 따라요. 프롬프트를 보낼 수 있는 기기는 누구나 새로 시작하고 메시지를 보낼 수 있어요. 사람에게는 명령 실행, 파일 수정, 샌드박스 밖 권한, Codex의 질문을 물어요. MCP 서버가 보내는 입력 양식은 거절하고, 그 밖의 요청도 거절로 답해서 Codex가 그 없이 이어 가요. 세션 목록은 `~/.choibuddy/codex-chats.json`(id, 폴더, 모델, effort, 기록 파일 경로)에 남겨요.
- **자동 언어**는 Claude Code가 Stop 훅에 넘기는 마지막 답 글자만 읽고, 언어 판단은 브리지에서 해요(코드, 경로, 링크는 빼고). 보낼 때는 동반 mod로 프롬프트 하나만 보내요. 연결된 기기는 누구나 켜고 끌 수 있어요. 바꾼 이름과 보관함은 `~/.choibuddy/sessions.json`에 저장하고, Claude Code의 기록 파일은 건드리지 않아요.
- **터미널.** 앱 안 터미널은 입력한 것을 그 PC에서 내 권한으로 무엇이든 실행해요. 앱 터미널에서 연 Codex에 보낸 프롬프트는 그 터미널에 글자로 입력돼요. 제어 문자는 빼서, 메시지가 키 입력으로 바뀌지 않아요.
  - 그 PC의 앱은 언제나 쓸 수 있어요. 휴대폰과 다른 PC는 그 PC 위험 구간의 **다른 기기에서 터미널 쓰기**를 켰을 때만 써요(기본은 꺼짐, PC 앱에서만 바꿔요). 끄거나, 기기 연결을 끊거나, 코드를 바꾸면 그 기기가 보던 터미널 화면도 바로 끊겨요.
  - Codex의 첫 프롬프트는 글자 그대로 하나의 문자열로 넘겨요. 따옴표(둥근 따옴표 포함)나 제어 문자로 셸에 끼어들 수 없어요.
  - PC에 새 창으로 열 때는 고른 폴더가 실제로 있을 때만 띄우고, 셸을 거치지 않고 프로그램과 인자를 따로 넘겨요. 이때 Codex에는 첫 프롬프트를 넘기지 않아요.
- **내장 브라우저.** 페이지에는 앱의 기능(IPC)이 열리지 않아요. 페이지가 앱에 알리는 것은 고른 요소와 주소뿐이에요. Claude의 `browser_view`에는 브라우저를 열어 둔 연결된 ChoiBuddy 앱(이 PC의 앱, 또는 이 PC를 연결한 다른 PC의 앱)이 답하고, 먼저 온 답이 쓰여요. 프롬프트를 보낼 수 있는 기기는 Claude에게 페이지도 보여 줄 수 있다는 뜻이에요. 브라우저가 닫힌 앱은 3초 기다렸다가 닫혀 있다고 답해서, 열린 앱이 먼저 답해요.

## 알아 둘 점

- 기본 권한 모드가 `bypassPermissions`이면 일반 권한 요청은 뜨지 않아요. Claude의 질문(AskUserQuestion)과 계획 승인은 그 모드에서도 떠요.
- 브리지가 꺼져 있으면 훅이 실패 메시지를 남길 수 있어요. 세션이 시작될 때와 프롬프트를 보낼 때 브리지를 자동으로 다시 띄워요.
- 실시간 코드와 사용량, 원격 프롬프트는 동반 mod가 필요해요. mod를 새로 깔거나 올린 뒤 이미 열려 있던 세션은 `/reload-plugins`가 한 번 필요해요. 대화 화면의 버튼으로 하거나 터미널에서 치면 돼요.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `bridge/` | Node 24 서버. 훅을 받아 상태를 만들고, 승인 요청을 붙잡고 있다가 답을 돌려줘요. 의존성은 앱 안 터미널용 node-pty 하나예요 |
| `shared/protocol.ts` | 브리지와 화면이 함께 쓰는 데이터 형식 |
| `ui/` | 화면(React). 윈도우 앱과 안드로이드 앱이 같은 빌드를 써요 |
| `windows/src-tauri/` | 윈도우 위젯(Tauri 2): 테두리 없는 창, 트레이, 항상 위, 시작 시 실행 |
| `android/` | 안드로이드 앱: WebView 화면, 승인 알림, 홈 화면 위젯 |
| `mod/` | Claude Code 안에서 도는 동반 mod: 사용량·모델·effort 보고, 원격 프롬프트와 슬래시 명령 전달, 쓰는 중인 코드와 답 전달, `browser_view` 도구 |
| `scripts/demo.ts` | 가짜 작업을 브리지에 흘려 화면을 확인하는 개발용 스크립트 |

## 빌드

```
corepack pnpm test         # 브리지 테스트
corepack pnpm typecheck    # 브리지 + 화면 타입 검사
corepack pnpm build        # 화면 빌드 (ui/dist)
corepack pnpm tauri build  # 윈도우 설치 파일, macOS에서는 .app과 .dmg (먼저 그 OS용 Node.js를 windows/src-tauri/runtime에 받아 고정된 SHA-256으로 확인하고, node-pty를 옆에 복사)
cd windows/src-tauri; cargo test
cd mod; claude plugin validate .; claude plugin test .
cd android; .\gradlew.bat --no-daemon testReleaseUnitTest assembleRelease lintRelease   # JAVA_HOME은 JDK 21
```

화면만 볼 때: 브리지를 시험용 포트로 띄우고(`CLAUDE_CONFIG_DIR`를 `<임시 폴더>/choibuddy-demo/claude`로) `node scripts/demo.ts --port <포트> --scene read|edit|bash|done|pending|question|plan|multi|agents|images|live|reply|command`를 실행한 뒤, 브라우저에서 `http://localhost:1430/#choibuddy://pair?u=...&t=...`를 열어요. 버전마다 바뀐 점은 [CHANGELOG.md](CHANGELOG.md)에 있어요.
